# 心屿 · Xinyu

**记录相遇，安放回忆。**

心屿是一款本地优先的私人关系手账。无论是刚认识、正在约会、单相思，还是已经成为情侣，都可以在这里整理人物、约定、照片、共同花费与自己的感受。

不需要双方绑定，不给关系打分，也不是交友匹配平台。

> 当前处于早期测试阶段。本仓库用于发布安装包、更新日志和接收反馈，不包含应用源代码。部分测试包仍使用开发名称 **CrushOS**；请以每个版本的说明为准。

[Mac 1.6.4 测试版](https://github.com/lixuanan2/xinyu/releases/tag/macos-v1.6.4) · [所有发布](https://github.com/lixuanan2/xinyu/releases) · [反馈问题](https://github.com/lixuanan2/xinyu/issues)

## 可以做什么

- **人物与关系**：记录感兴趣的人，自定义当前关系和状态。
- **约会准备**：先写不定日期的草稿，列准备清单，确定后再安排到日历。
- **日历与记录**：整理约定、生日和纪念日，完成约会后留下互动与回忆。
- **相册与花费**：保存照片和描述，记录双方付款及 AA 分摊。
- **查找与整理**：搜索记录，用简洁的黑白灰界面回顾自己的故事。

手机适合随手记录，Mac 适合搜索和整理。两端功能并非完全一致，具体以版本说明为准。

## 数据与隐私边界

- 当前业务记录保存在设备本地；尚未提供账号登录、自动云备份或双端同步。
- macOS 支持手动 `.crushos` 备份与恢复。该备份目前未加密，请妥善保管。
- Android 手动导出/恢复和基础应用锁尚未完成。重要内容请保留其他副本；卸载或清除应用数据可能导致本地内容丢失。
- 本地保存不等于数据库已加密，也不等于所有平台都已具备应用锁。
- macOS 的可选 GitHub 更新检查会访问 GitHub；反馈和下载也由 GitHub 承载。

这些说明用于帮助测试用户理解当前能力，不替代未来正式发行所需的完整隐私政策。
